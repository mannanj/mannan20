## Pinch cursor

- Goal: a cursor that squeezes what it clicks, pinching the page, not a hand facing the viewer.
- Draft: thumb and index finger open around the click point, closing on press. Generated by `pinch-cursor/gen.mjs` (`node gen.mjs` writes `open.svg`, `closed.svg` and `css.txt` with the `cursor:` values, hotspot 10 46).
- Why it was pulled: a 60 px cartoon hand with a blue sleeve does not read as a cursor. Next try should look like a system cursor (small, crisp outline) that still pinches.
- The site uses the original hand cursor in `.chicken-hand-cursor` (`src/app/globals.css`).
